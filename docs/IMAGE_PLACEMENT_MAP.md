## Deliberately NOT included

### Dedicated location image/map

None of the selected official assets proves the exact geographic/site context strongly enough to use as a dedicated location map. Keep Location factual and minimal until verified location material is supplied.

### Separate community courtyard image

Do not invent a community courtyard amenity because the generated project previously used a stock image for it.

### Fake floor-plan SVG

Prefer the supplied actual architectural plans rather than generic generated SVG plans.

## Image integrity rules

- Do not claim an interior is a specific apartment unless verified.
- Do not claim an exact view/orientation from a render unless verified.
- Do not infer new amenities from what appears in a placeholder/generated visual.
- Do not add stock images after this package is used.
