# ONA Towers Frontend

Premium marketing and pre-sales concept for ONA Towers, Zanzibar.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Placeholder content

- All imagery in `public/placeholders/` is temporary architectural SVG artwork.
- Floor plans are conceptual interaction placeholders, not architectural drawings.
- The location map and labels require confirmed project data.
- WhatsApp, sales contact and social links remain intentionally unlinked until details are supplied.
- The enquiry form demonstrates frontend behaviour only and requires a backend/CRM integration.

Replace media by changing the `src` values passed to the shared `Media` component; layout code does not need to change.
