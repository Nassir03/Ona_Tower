# ONA Towers — Cinematic Property Campaign

A premium, scroll-led architectural campaign built with Next.js, TypeScript, Framer Motion, Tailwind CSS and the supplied ONA cinematic image pack.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Homepage narrative

Arrival → Vision → Development masterplan → Residences → Residence types and plans → Interiors → Lifestyle → Commercial → Architecture facts → Location → Enquiry.

The former deep masterplan/tower/floor/room explorer is no longer the homepage experience. The masterplan now provides light spatial orientation, and practical plans appear later through accessible plan viewers.

## Assets

The 27 supplied cinematic image files are installed under `public/ona-assets/`. All runtime paths and verified project facts are centralized in `data/cinematic.ts`.

## Content limitations

- No prices, availability, unit IDs, payment plans or exact unit views were fabricated.
- Derived 2BR and 4BR plan crops are labelled as presentation plans.
- Interior images are described as visualizations because exact unit mapping is unconfirmed.
- The location section intentionally omits an address, travel times and landmarks until verified data is supplied.
- The enquiry form remains frontend-only until connected to the confirmed sales/CRM service.

## Design influences

- Mercedes-Benz Places: cinematic restraint, dominant imagery, typography and pacing.
- One Za'abeel: residences, lifestyle and commercial presented as one destination.
- Tomorrow World: clear residence metadata and floor-plan access.
- Al Barari: a simplified, accessible masterplan orientation section.
