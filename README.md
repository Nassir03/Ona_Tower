# ONA Towers — VS Code Ready Package

This package contains the current Google AI Studio ONA Towers frontend, the selected official ONA images/plans, and one final Codex prompt for replacing all temporary imagery and completing the factual accuracy pass.

Start with:

1. `START_HERE_VSCODE_GIT.md`
2. `CODEX_FINAL_PROMPT.md`
3. `IMAGE_PLACEMENT_MAP.md`

Local setup:

```bash
npm install
npm run dev
```

Validation:

```bash
npm run lint
npm run build
```

Do not push until the Codex pass has been visually reviewed.
